# 🌱 AgriCrop

An AI-powered web application for plant disease detection and soil moisture prediction.

## ✨ Features

- 🌿 Plant Disease Detection using MobileNetV2
- 💧 Soil Moisture Prediction
- 🗄️ MongoDB Database Integration
- 🗺️ Geospatial Disease Map
- 📊 Analytics Dashboard
- 💡 AI-Based Treatment Recommendations
- 🔍 Search and Filter History

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Backend:** Flask
- **AI/ML:** TensorFlow, MobileNetV2
- **Database:** MongoDB
- **Frontend:** HTML, CSS, JavaScript
- **Maps:** Leaflet.js

## 📂 Dataset

PlantVillage Dataset
