# AgriCrop

AI-powered web application for plant disease detection and soil moisture prediction.

## Features

- Plant Disease Detection (MobileNetV2)
- Soil Moisture Prediction
- MongoDB Database
- Geospatial Disease Map
- Analytics Dashboard
- AI Treatment Recommendation
- Search & Filter History

## Technologies

- Python
- Flask
- TensorFlow
- MobileNetV2
- MongoDB
- Leaflet.js
- HTML
- CSS
- JavaScript

## Dataset

PlantVillage Dataset
